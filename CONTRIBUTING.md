# Contributing

Contributions are welcome.

Please keep the project focused: a small, free reminder capability for GitHub issues and pull requests with minimal permissions and no unnecessary hosted infrastructure.

Before opening a pull request:

1. Keep changes narrowly scoped.
2. Add or update tests for behavioral changes.
3. Run `npm run check` with Node.js 20 or later.
4. Avoid adding runtime dependencies unless they solve a demonstrated problem that cannot be handled safely with the Node.js standard library.
5. Preserve backward compatibility for versioned reminder metadata where practical.

Security-sensitive changes should receive extra review before release.
